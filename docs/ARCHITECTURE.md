# Repository architecture

## Current executable tooling

The repository contains metadata, source-provenance, workflow, dependency-alignment, documentation, inventory and preflight controls, plus native-tool bootstrap. Each inspects its fixed declared scope. Received metadata cannot select another policy or grant numerical acceptance. Foundation qualification is in progress.

## Intended analysis boundaries

| Component | Responsibility | Required evidence |
| --- | --- | --- |
| Prior plan | Full population, source law, tested lengths, numerical protocol and stopping rule | Exact existing preregistration and applicable qualification |
| Acquisition | Separate simulation or qualified fabric capture | Complete raw cells, source identity, reset, warmup and sampling |
| Circuit oracles | Seven source-specific arithmetic variants | Independently checked joint law and actual native semantics |
| Analysis | Finite metrics and six statistical methods with explicit applicability | Whole population, actual source law, coverage and numerical admission |
| Sweep decisions | Strict interval decisions, first qualifying tested point and whole aggregate | All prior points, all later failures and explicit point limitations |
| Evidence | Existing candidate through installed shared provider | Separate common, owner, current-context and arithmetic results |
| Consumers | Verified existing native reports | Actual producer/consumer interfaces and complete scope |

The intended native report has twelve root fields: schema_id, claims, source_ref, environment_ref, experiment, lane, source_certificates, source_status, statistics, sweep, minimum_stream_length and verdict. This declared format is not registered or qualified by this checkout.

The four prospective public operations are run, analyse, report and verify. They are not installed or advertised as available commands. Acquisition preserves every planned slot; analysis does not invent missing observations; reporting can honestly retain a bound violation. Verification keeps required eligibility and required within-bounds acceptance distinct.

The seven circuit variants are joint AND, stationary CORDIV, finite-reset CORDIV, subset-quotient CORDIV, joint MUX, independent-selector MUX and width-16 decorrelation. Current source CORDIV reset is zero. Reset and warmup are retained but uncounted; settled clocked post-update sampling differs from an abstract native update. Literal bits must be validated before conversion, and full lengths, packing and padding must be admitted before imported helpers.

The six intended statistical branches are finite data, independent Bernoulli Clopper–Pearson, independent run-summary DKW, independent Welch equivalence, evidenced paired equivalence and outer-replicate joint-power Clopper–Pearson. Their assumptions cannot be inferred from equal seeds or a source battery. Exactly normal models cannot describe nondegenerate bounded bit-error summaries. Missing coverage or source admission leaves inference unavailable while finite observations persist.

A finite prefix needs its actual applicable bound. Fixed-length confidence does not automatically survive adaptive stopping. A tested minimum names one qualified tested point; later failures remain and can determine the whole aggregate. Strict uncertainty contact or overlap is inconclusive. Read [validation tooling](validation-tooling.md) for executable repository interfaces.
