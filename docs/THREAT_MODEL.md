# Data and authority boundaries

## Present tooling

The maintained checkout and selected development environment are execution inputs for repository controls. Received descriptors, dependency receipts and generated inventories cannot nominate acceptance policy or executables. Checks inspect bounded local scopes and report fixed diagnostics. Source byte identity is separate from numerical correctness, scientific qualification, current trust and hosted execution.

An inventory is not a concurrent filesystem snapshot or power-failure durability guarantee. Native child processes use maintained finite argument vectors and direct-child deadlines; completed-output limits are not live volume ceilings. Foundation qualification is in progress.

## Future numerical inputs

Plans, streams, reports, reference objects and source certificates are supplied data. They do not grant program execution, acquisition, signing, publication or device authority. Independently configured methods and source-specific admission must precede interpreting those objects.

Validate literal bits before narrowing conversion. Preserve complete declared lengths, tails, packing, padding, populations and failed slots. No truncation, unavailable-to-zero conversion or favourable post hoc source selection is admissible. Strict interval contact stays inconclusive. Fixed-length assumptions do not automatically justify adaptive stopping. Source batteries and paired seeds cannot establish independence.

False execution means confirmed nonexecution and null means unknown execution; neither supplies a computed result. A performed result requires its actual algorithm and trace. Immutable chronology must avoid cycles between evidence, admission and plan. Honest arithmetic failure and evidence eligibility remain separate.

Acquisition, numerical methods, source-law admission, coverage, installed provider integration and operational recovery remain unimplemented domain boundaries. No runtime isolation, numerical reliability, physical control or durability guarantee is claimed.
