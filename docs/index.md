# SC Stream Prover

This repository is preparing a tool for independently checking stochastic arithmetic against explicitly scoped models. Its current executable surface is repository validation tooling. It has no installed arithmetic-analysis package, public circuit runner or qualified numerical report.

The intended workflow preserves the prior source and numerical assumptions, complete raw populations, finite metrics, applicable bounds, every tested point and separate evidence eligibility. Simulation and physical capture retain distinct origin. A tested minimum does not guarantee all greater lengths.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
