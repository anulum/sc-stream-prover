# Architecture

## Current executable surface

The checkout contains repository validation tooling, dedicated tests, workflow definitions and native documentation. No arithmetic-analysis package, acquisition adapter, statistical method or numerical report is qualified. Metadata keeps domain capabilities and claims empty.

## Intended data flow

An exact prior plan selects the full source law, population, circuit, numerical method, tested lengths, reset, warmup and sampling semantics before acquisition. A separately qualified simulation or fabric adapter retains complete raw cells and explicit failed or missing slots. Independent analysis produces a complete native candidate. The installed shared evidence provider seals existing bytes. Verification retains separate common eligibility, owner conformance, exact context and arithmetic verdict.

## Ownership

SC Stream Prover owns arithmetic experiments and reports. SC-NeuroCore retains circuits and their native counterparts. Randomness Witness owns source certificates; Loop Timing Witness owns capture and timebase; Evidence Manifest Toolkit owns shared evidence operations; Experiment Ledger owns generic storage. Studio and downstream consumers render or consume admitted existing evidence.

## Numerical interpretation

Joint source laws, selector dependence and stateful sampling matter. A finite exact observation cannot supply an unqualified bound or source independence. A tested minimum carries its individual-point scope and later failures. Strict interval contact remains inconclusive. Arithmetic failure can be reported honestly while evidence eligibility is checked separately.
