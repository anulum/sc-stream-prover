## Evidence limits

Source identity differs from installed behaviour, numerical correctness and independent qualification. Static workflow checks differ from hosted execution. A finite deterministic result is not a confidence guarantee. A passing source battery is not an independence proof. No source law, device result, operational source certificate, release, DOI, performance comparison or hosted service follows from the maintained repository tools.
